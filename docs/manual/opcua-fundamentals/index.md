# OPC UA Fundamentals

OPC UA defines object-oriented information models that live in an OPC UA
server, and a protocol that clients use to interact with those models over the
network.

This chapter introduces the core concepts of OPC UA. For the full
specification, see the [OPC UA standard](https://reference.opcfoundation.org/).
